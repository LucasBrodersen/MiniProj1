## Declaração de uso de IA

O código da aplicação (componentes Vue, estilos e navegação) foi desenvolvido por mim.
Usei um assistente de IA (Claude, da Anthropic) apenas como apoio nas seguintes tarefas:

- **Preparação do ambiente:** gerar um prompt para um agente instalar o Node.js (nvm)
  no WSL2 e criar o projeto com `npm create vue@latest`, com as opções por omissão.
- **Revisão:** analisar o repositório e sugerir melhorias (por exemplo, usar links
  internos por hash, adicionar um `h1`, remover um componente não utilizado).
- **Documentação:** montar o PDF dos wireframes a partir dos meus ficheiros SVG.

Prompts principais utilizados:
1. "Me dê um prompt para o agente fazer as instalações das dependências para eu iniciar
   o projeto, eu quero tudo como vem instalado para eu começar a programar."
2. "Analise o meu repositório de PWA e veja se está bem o projeto."
3. "Veja os wireframes, estão agora no repositório seguem os textos (…), compile-os em um o PDF para mim"

Todas as sugestões foram revistas por mim antes de serem aplicadas.
